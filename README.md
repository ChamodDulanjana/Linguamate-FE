# Linguamate Mobile App (Flutter)

Linguamate Mobile App is the **Flutter-based frontend** for the **Linguamate AI Language Learning Platform**. This app allows users to learn languages interactively while leveraging AI-powered features provided by the Linguamate backend.

The application is designed with a clean UI, smooth UX, and scalability in mind, targeting **Android (and future iOS)** platforms.

---

## 📱 Features

* AI-powered language learning experience
* Language detection & smart responses
* Clean and modern UI
* Fast and responsive performance
* Backend integration via REST APIs

---

## 🚀 Tech Stack

* **Flutter (Dart)**
* **Material UI**
* **REST API Integration**
* **HTTP / Dio** (for API calls)
* **State Management** (Provider / Riverpod / Bloc – as needed)

## ⚙️ Prerequisites

Make sure you have the following installed:

* **Flutter SDK (3.x or later)**
* **Dart SDK** (comes with Flutter)
* **Android Studio / VS Code**
* **Android Emulator or Physical Device**

Check Flutter installation:

```bash
flutter doctor
```

---

## 📦 Install Dependencies

From the project root, run:

```bash
flutter pub get
```

---

## 🔗 Backend Configuration

The app communicates with the **Linguamate Backend API**.

Update the base API URL inside your API service file, for example:

```dart
const String baseUrl = "http://10.0.2.2:8000"; // Android Emulator
```

For physical devices, replace with your machine’s local IP or deployed backend URL.

## 🧹 Git Ignore Rules

The following files/folders should NOT be committed:

* `build/`
* `.dart_tool/`
* `.idea/`
* `*.iml`
* `*.log`

These files are auto-generated by Flutter and IDEs.
